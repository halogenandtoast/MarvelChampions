# The Hood: modular and alternate encounter sets

Card text from the local MarvelCDB index. See scenario-the-hood.md for the official rules insert source. Standard II replaces Standard; Expert II replaces Expert and can be paired with either Standard set. Formidable Foe uses its expert side in expert mode.

## 24014 — Beast Mode

<b>Forced Interrupt</b>: When a stunned or confused friendly character would take any amount of damage, increase that amount by 1.

## 24015 — Griffin

Quickstrike.
[star] <b>Forced Response</b>: After Griffin attacks and damages a character, stun that character.
<b>When Defeated</b>: If there is a stunned friendly character in play, shuffle Griffin into the encounter deck.
